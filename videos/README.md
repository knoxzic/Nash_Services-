# Video Background Files

This directory contains background videos for the NASH Services portal.

## Required Files

1. **bg-1.mp4** - Hero section background video (recommended: 1920x1080, 5-10 seconds loop)
2. **bg-2.mp4** - Service request section background video (recommended: 1920x1080, 5-10 seconds loop)

## Instructions

Place your MP4 video files in this directory. The videos should be:
- **Format:** MP4 (H.264 codec)
- **Resolution:** 1920x1080 (16:9 aspect ratio) or higher
- **Duration:** 5-30 seconds (will loop continuously)
- **Size:** Optimized for web (under 10MB recommended)

The videos will automatically loop in the background with a semi-transparent dark overlay (40% opacity) for text readability.

## Video Suggestions

- **bg-1.mp4 (Hero):** Professional property/cleanup services, moving trucks, team working, before/after transformations
- **bg-2.mp4 (Request Form):** Action shots of cleaning/removal services in progress, satisfied customers, professional team
